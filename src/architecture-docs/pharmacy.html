What This Context Does

Pharmacy & Rx manages the entire medication lifecycle — from the moment a doctor writes a prescription to when the patient picks up a refill months later. Its most critical function is drug interaction checking: before any prescription is finalized, the system cross-references it against the patient's allergy list (from Patient Management) and their current medications to catch dangerous combinations.

For example, if a patient is allergic to penicillin and a doctor prescribes amoxicillin (a penicillin-class antibiotic), this service raises an alert before the prescription reaches the pharmacy counter.

In plain English: This is the hospital pharmacy's brain. It knows what medications a patient is on, checks every new prescription for safety, tracks refills, and alerts when something dangerous might happen. It's one of the most patient-safety-critical parts of the entire EHR.

Medication Entity

Drug catalog entry. NDC code, class (antibiotic, NSAID, etc.), contraindications, standard dosing. Referenced by prescriptions.

Refill Entity

Each time a prescription is filled. Tracks fill date, pharmacy location, quantity dispensed. Decrements RefillsRemaining.

DrugInteraction Value Object

The result of checking a prescription against allergies and current medications. Includes severity (Warning, Contraindicated), the conflicting drug/allergy, and clinical recommendation. Immutable — computed at prescription time.

Drug Interaction Checking — How It Works

When a new prescription is created, the pharmacy service:

  1. Fetches the patient's allergy list from Patient Management
  2. Fetches the patient's active prescriptions from its own database
  3. Checks the new drug against all known allergies (cross-sensitivity rules)
  4. Checks the new drug against current medications (drug-drug interactions)
  5. Returns a list of DrugInteraction results with severity levels
  6. If Contraindicated: blocks the prescription and alerts the doctor
  7. If Warning: allows with doctor override + audit log entry
