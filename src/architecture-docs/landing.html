📋 Documentation & Strategy Guides

Technical deep-dives on migration patterns, resilience, and API design.

🧩
Domain Decomposition
6 bounded contexts → microservices. Patient, Clinical, Scheduling, Pharmacy, Lab, Provider — each with its own database, API, and event contracts.
🌿
Strangler Fig Pattern
Monolith-to-microservices migration: facade install, dual-write via Kafka, canary shifting with Istio, Anti-Corruption Layer per bounded context.
🔌
TCP → HTTPS Migration
Replace raw TCP with HTTPS/REST + Istio mTLS. Ingress TLS termination, AuthorizationPolicy, NetworkPolicy lockdown, contract-first API design.
⏱️
RTO / RPO Requirements
4-tier service classification. PostgreSQL zone-redundant HA, PodDisruptionBudgets, Kafka event replay for Tier 3, monitoring alerts.
🔀
API Version Catalog
v1 (basic CRUD), v2 (paginated DTOs + dashboard), v3 (FHIR R4 + AI decision support). URL-based versioning with multi-version Swagger.
📅
K8s Upgrade Planner
Interactive tool: pick a date, K8s version, node count → get a multi-week schedule with Azure CLI commands, heatmap calendar, and CSV export.
