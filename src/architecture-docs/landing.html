Azure PostgreSQL Flexible Server DATABASE
ehrdb-canadacentral.postgres.database.azure.com

The Azure Database for PostgreSQL — Flexible Server instance powering all EHR data persistence. Runs PostgreSQL 16 on a Burstable B2s SKU with 32GB storage. Currently a single database (ehrdb) that will be decomposed into per-service databases as microservice extraction proceeds.

Version
PostgreSQL 16
Storage
32 GB
Database

  • 8 tables: Patients (15), Providers (8), Appointments (20), MedicalRecords (15), Prescriptions (18), LabResults (20), Allergies (12), Vitals (25)
  • 133 total seed records with realistic healthcare data
  • SSL required — all connections encrypted with TLS 1.2+
  • Firewall rule: AllowAllAzure (0.0.0.0) for Azure service access
  • Burstable tier — cost-effective for development with burst capability
  • Automatic backups with 7-day retention
  • Target: decompose into 6 per-service databases (patient-db, clinical-db, scheduling-db, pharmacy-db, lab-db, provider-db)
